# Neurocomputing submission package

The manuscript is built with the unmodified Elsevier CAS double-column
class copied from `paper/els-cas-templates`.

Final PDFs to upload:

1. `submission_files/final/Cover_Letter.pdf`
2. `submission_files/final/Manuscript.pdf`

Author details remain in the manuscript because Neurocomputing uses
single-anonymized peer review. The abstract is below 250 words, the
keyword count is within one to seven, and the five highlights are each
within the 85-character limit.
