# ESWA submission package

The manuscript uses the unmodified Elsevier CAS double-column class copied
from `paper/els-cas-templates`.

Final PDFs to upload:

1. `submission_files/final/Cover_Letter.pdf`
2. `submission_files/final/Title_Page.pdf`
3. `submission_files/final/Manuscript_without_author_details.pdf`
4. `submission_files/final/Highlights.pdf`
5. `submission_files/final/Declaration_of_Interest_Statement.pdf`
6. `submission_files/final/ORCID_Information.pdf`

Anonymization check for the manuscript:

- no author names, affiliations, e-mail addresses, ORCID iDs, or CRediT block;
- no identifiable repository URL;
- author details are confined to the title page and administrative files.

The production source can restore the public repository URL and author
front matter after peer review.
